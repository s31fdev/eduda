## Что это было

Колонка жила с `0_init`, отношения к чему-либо в схеме не имела, ни один экшен её
не читал и не писал. Значения семизначные, в диапазоне 1 695 973 … 1 762 511, идут
не подряд — похоже на идентификаторы продуктов во внешней системе, из которой
данные «Алгоритмики» заезжали в `0_init`.

## Статус

Решено удалить (17.08.2026). Миграция `20260817120000_rename_product_models`
делает `ALTER TABLE "Product" DROP COLUMN "productId"`; на дев-базе уже
отработала, на проде удалит эти значения при выкатке. **Этот файл — единственная
их копия.**

Если внешние коды понадобятся справочнику продуктов (карточка #82), брать их
отсюда: колонка возвращается как `externalId`, значения заливаются по `id`.
